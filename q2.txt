- Total memory usage with floats: 6 * 4 + 12 * 4 = 72 bytes 
- Total memory usage with doubles: 6 * 4 + 12 * 8 = 120 bytes

When either approach wins:
If we need to assign attributes/characteristics to each vertex for each triangle, then we need to store all 6 verticies. In case the two triangles share a vertex with the same position but different attributes. Otherwise, theres no reason not to use the 4 vertex method.
